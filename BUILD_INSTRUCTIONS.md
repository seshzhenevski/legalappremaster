# Сборка приложения с нуля — пошаговая инструкция

Эта инструкция проведёт вас от чистого компьютера с Windows до готового
установочного `.exe`-файла «Юридического инструментария». Никакого опыта
программирования не требуется — просто выполняйте шаги по порядку.

> **Сколько времени займёт:** первая сборка ~40–60 минут, из них большая
> часть — установка инструментов и скачивание. Все последующие сборки — 3–5 минут.
>
> **Что получится в итоге:** установщик в папке
> `src-tauri\target\release\bundle\` — его можно передавать коллегам.

## Шаг 1. Установка инструментов

Приложение собирается из трёх «кирпичей»: интерфейс (JavaScript), логика
(Python) и оболочка (Rust). Для каждого нужен свой инструмент. Устанавливайте
строго по порядку — некоторые зависят от предыдущих.

### 1.1. Microsoft C++ Build Tools

Это набор компиляторов от Microsoft. Rust без них не соберёт приложение.

1. Откройте страницу: <https://visualstudio.microsoft.com/visual-cpp-build-tools/>
2. Нажмите **Download Build Tools**, запустите скачанный файл.
3. В открывшемся окне installer'а поставьте галочку **«Разработка классических
   приложений на C++»** (*Desktop development with C++*).
4. Нажмите **Установить**. Скачается ~2–4 ГБ, это нормально.
5. После установки **перезагрузите компьютер**.

### 1.2. WebView2

Это движок, который рисует интерфейс приложения (как встроенный браузер).

> **Возможно, уже установлен.** На Windows 10 (версии 1803 и новее) и Windows 11
> WebView2 уже есть. Проверять не обязательно — если он есть, установщик просто
> сообщит об этом. Пропустите этот пункт, если не уверены, и вернитесь к нему,
> только если сборка пожалуется на WebView2.

1. Откройте: <https://developer.microsoft.com/microsoft-edge/webview2/>
2. В разделе загрузок скачайте **Evergreen Bootstrapper**.
3. Запустите и установите.

### 1.3. Rust

Это язык, на котором написана оболочка Tauri.

1. Откройте: <https://www.rust-lang.org/tools/install>
2. Скачайте **rustup-init.exe** (кнопка для 64-bit Windows).
3. Запустите файл. Откроется чёрное окно с текстом.
4. Когда спросит вариант установки — просто нажмите **Enter** (вариант по
   умолчанию «1) Proceed with standard installation» — то, что нужно).

   > **Важно:** по умолчанию Rust выберет правильный «MSVC» вариант, который
   > нужен для Tauri. Если вы раньше уже ставили Rust, откройте PowerShell
   > и выполните `rustup default stable-msvc`, чтобы гарантировать нужную версию.

5. Дождитесь надписи *«Rust is installed now. Great!»*.
6. **Закройте все окна терминала** — Rust появится в новых окнах.

### 1.4. Node.js

Нужен для инструмента сборки Tauri (Tauri CLI).

1. Откройте: <https://nodejs.org>
2. Скачайте версию с пометкой **LTS** (слева, «рекомендуется для большинства»).
3. Установите, ничего не меняя в настройках (все галочки по умолчанию).
4. **Перезагрузите компьютер** (или хотя бы закройте все терминалы).

### 1.5. Python

На нём написана вся расчётная логика.

> Если Python уже установлен (вы запускали приложение из исходников раньше) —
> пропустите этот пункт.

1. Откройте: <https://www.python.org/downloads/>
2. Скачайте последнюю версию Python 3 (3.10 или новее).
3. **Критично:** на первом экране установщика поставьте галочку
   **«Add Python to PATH»** (внизу окна). Без неё команды `python` не будут
   работать.
4. Нажмите **Install Now**.

## Шаг 2. Проверка установки

Прежде чем собирать, убедимся, что все инструменты «видны». Откройте
**PowerShell** (нажмите Win, наберите «PowerShell», Enter) и выполните команды
по одной. Каждая должна вывести номер версии, а не ошибку.

```powershell
rustc --version
cargo --version
node --version
npm --version
python --version
```

**Как должно выглядеть** (номера версий у вас могут отличаться — это нормально):

```
rustc 1.86.0 (...)
cargo 1.86.0 (...)
v20.11.0
10.5.0
Python 3.12.2
```

> Если какая-то команда пишет *«не является внутренней или внешней командой»* —
> значит, этот инструмент либо не установлен, либо нужно перезагрузить
> компьютер, чтобы система его увидела. Вернитесь к соответствующему пункту Шага 1.

## Шаг 3. Подготовка проекта

1. Распакуйте архив `trivio-legal.zip` в удобную папку, например в
   `C:\trivio-legal`. Путь **не должен содержать русских букв и пробелов** —
   некоторые инструменты этого не любят. `C:\Projects\trivio-legal` — хорошо,
   `C:\Мои документы\проект` — плохо.

2. Откройте PowerShell **в папке проекта**. Самый простой способ: откройте папку
   в Проводнике, зажмите **Shift**, кликните правой кнопкой по пустому месту →
   **«Открыть окно PowerShell здесь»**.

3. Установите Tauri CLI — инструмент, который управляет сборкой. Выполните:

   ```powershell
   npm install
   ```

   Это скачает нужные пакеты в папку `node_modules`. Займёт 1–2 минуты.

4. Установите Python-библиотеки и PyInstaller (он превратит Python в `.exe`):

   ```powershell
   pip install -r src-python\requirements.txt
   pip install pyinstaller
   ```

## Шаг 4. Сборка Python-sidecar

Логика на Python должна стать отдельным `.exe`-файлом, который оболочка будет
запускать внутри себя. За это отвечает готовый скрипт `build_sidecar.py`.

Выполните:

```powershell
npm run build:sidecar
```

**Что произойдёт:**
- PyInstaller соберёт всю Python-логику в один файл;
- скрипт определит вашу платформу и переименует файл в нужный формат
  (например `legal-sidecar-x86_64-pc-windows-msvc.exe`);
- положит его в папку `src-tauri\binaries\`.

**Как понять, что получилось:** в конце появится строка вида
`Готово: ...\src-tauri\binaries\legal-sidecar-x86_64-pc-windows-msvc.exe`.
Загляните в папку `src-tauri\binaries\` — там должен лежать этот файл размером
30–60 МБ.

> **Зачем такое длинное имя?** Tauri требует, чтобы имя sidecar заканчивалось
> «идентификатором платформы». Скрипт делает это за вас — вручную ничего
> переименовывать не нужно.

## Шаг 5. Сборка приложения

Теперь собираем всё вместе в установщик. Выполните:

```powershell
npm run build
```

**Что произойдёт** (это самый долгий шаг, 5–15 минут в первый раз):
- Rust скомпилирует оболочку Tauri (в первый раз он скачивает и собирает много
  вспомогательного кода — наберитесь терпения, окно может подолгу «висеть» на
  строчке `Compiling ...`, это нормально);
- Tauri упакует интерфейс, оболочку и Python-sidecar в единый установщик.

**Признак успеха** — в конце появятся строки вида:

```
Finished 2 bundles at:
    ...\src-tauri\target\release\bundle\nsis\Юридический инструментарий_5.0.0_x64-setup.exe
    ...\src-tauri\target\release\bundle\msi\Юридический инструментарий_5.0.0_x64_ru-RU.msi
```

## Шаг 6. Где готовый файл

Установщики лежат здесь:

```
src-tauri\target\release\bundle\
├── nsis\
│   └── Юридический инструментарий_5.0.0_x64-setup.exe   ← основной установщик
└── msi\
    └── Юридический инструментарий_5.0.0_x64_ru-RU.msi   ← альтернативный
```

**Который отдавать коллегам:** файл из папки `nsis\` (`...-setup.exe`) — это
обычный установщик, привычный любому пользователю Windows. Файл `.msi` —
альтернатива для корпоративной установки через групповые политики.

Коллеге достаточно запустить `-setup.exe` и пройти установку «Далее → Далее».
Ни Python, ни Rust, ни что-либо ещё на его компьютере **не нужно** — всё уже
внутри.

## Замена иконок перед раздачей

Сейчас у приложения иконки-заглушки (синие квадраты). Перед тем как отдавать
коллегам, замените их на настоящие:

1. Подготовьте квадратную картинку-логотип в формате PNG, минимум 512×512
   пикселей, назовите `app-icon.png` и положите в папку проекта.
2. Выполните команду (она сгенерирует все нужные размеры автоматически):

   ```powershell
   npm run tauri icon app-icon.png
   ```

3. Пересоберите приложение (Шаг 5).

## Быстрая пересборка (на будущее)

Когда всё установлено, для новой сборки после изменений в коде нужно всего два
шага в PowerShell из папки проекта:

```powershell
npm run build:sidecar    # только если менялась логика Python
npm run build            # собрать установщик
```

Если менялся только интерфейс (HTML/JS) — можно пропустить первую команду.

Для разработки с мгновенным просмотром изменений есть режим с горячей
перезагрузкой:

```powershell
npm run build:sidecar    # один раз, чтобы sidecar существовал
npm run dev              # откроется окно приложения, правки видны сразу
```

## Если что-то пошло не так

**`rustc` / `cargo` не найдены после установки Rust**
Перезагрузите компьютер. Rust добавляется в систему только для новых окон.

**`link.exe not found` или ошибки про MSVC при `npm run build`**
Не установлены C++ Build Tools (шаг 1.1) или не выбрана галочка «Разработка
классических приложений на C++». Переустановите с этой галочкой, перезагрузитесь.

**`failed to run light.exe` при сборке MSI**
Отключён компонент VBSCRIPT в Windows. Откройте *Параметры → Приложения →
Дополнительные компоненты → Другие компоненты Windows*, найдите **VBSCRIPT**,
включите, перезагрузитесь. Либо соберите только NSIS-установщик, изменив в
`src-tauri\tauri.conf.json` строку `"targets": ["nsis", "msi"]` на
`"targets": ["nsis"]`.

**`pip` не найден**
Python установлен без галочки «Add Python to PATH». Переустановите Python
(шаг 1.5), не забыв про галочку.

**Сборка sidecar падает с ошибкой про отсутствующую библиотеку**
Не установлены Python-зависимости. Выполните заново:
`pip install -r src-python\requirements.txt`.

**`npm run build` завершается ошибкой про sidecar / binaries**
Вы пропустили Шаг 4. Сначала `npm run build:sidecar`, потом `npm run build`.

**Окно `npm run build` долго «висит» на `Compiling`**
Это нормально при первой сборке — Rust компилирует сотни вспомогательных
пакетов. Подождите, не прерывайте. Последующие сборки будут быстрыми.

**Антивирус удаляет собранный sidecar**
Некоторые антивирусы подозрительно относятся к файлам, собранным PyInstaller.
Добавьте папку проекта в исключения антивируса и пересоберите.

## Проверка, что всё работает (перед раздачей)

Прежде чем отдавать установщик коллегам, проверьте его на своей машине:

1. Запустите собранный `-setup.exe`, установите приложение.
2. Откройте его из меню Пуск.
3. Проверьте каждую вкладку:
   - **Госпошлина:** введите `5000000`, нажмите расчёт → должно быть `175 000 ₽`.
   - **Неустойка:** добавьте задолженность, дату, ставку → расчёт должен пройти.
   - **Генератор иска:** выберите Excel-реестр и папку → должны создаться 3 файла.
   - **Сортировщик:** выберите папки, вставьте описание счетов → должны собраться пакеты.

Если все четыре вкладки отработали — установщик готов к раздаче.
