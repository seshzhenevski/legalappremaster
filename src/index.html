Настройка ключа DaData

Для поиска реквизитов по ИНН нужен бесплатный ключ dadata.ru:

  1. Зарегистрируйтесь на dadata.ru
  2. Откройте раздел «Личный кабинет → API-ключи»
  3. Скопируйте «Ключ API» (Api-Key)

Справка: Сортировщик документов

Сортировщик собирает пакеты «Счёт + Акт + УПД» из папки с PDF-файлами по описанию счетов, вставленному из 1С.

Формат описания одного счёта:

Счет на оплату № 65625 от 24.06.2025 на сумму 40 480 рублей
1. Акт приема-передачи № 206391 от 23.06.2025
2. УПД № 107867 от 23.06.2025

Можно вставить описания сразу нескольких счетов подряд — каждый начинается с новой строки «Счет на оплату № …».
